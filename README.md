A modern, responsive e-commerce landing page for an electronics and gadgets storefront. Built with HTML5, custom CSS3, and Bootstrap 5 as an early responsive web design project.

---

## 🔗 Live Preview

Explore the live storefront on GitHub Pages:  
👉 **[View Live Demo](https://tawsifx.github.io/hot-gadgets/)**

---

## ✨ Features

- **Responsive Navigation**: Brand logo, navigation menu, and search bar powered by Bootstrap Navbar.
- **Hero Slider Carousel**: Interactive banner carousel highlighting flagship product deals.
- **Smartphone Showcase**: Product card gallery featuring top phones (e.g., iPhone 11 Pro, Samsung Galaxy Note 10+) with pricing and buy-now actions.
- **Laptop Showcase**: Catalog section displaying high-performance laptops and ultrabooks (e.g., Apple MacBook Pro, Asus ROG).
- **Category Highlights**: Dynamic product categories with custom background graphics and icons.
- **Mobile-First Responsive Layout**: Smooth scaling across mobile devices, tablets, and desktop displays.

---

## 🛠️ Built With

- **HTML5**: Semantic structure
- **CSS3**: Custom themes, borders, shadows, and card styling
- **Bootstrap 5 (5.0.2)**: Grid system, carousel slider, card components, and utility classes
- **Google Fonts**: [Poppins](https://fonts.google.com/specimen/Poppins)
- **GitHub Pages**: Static site hosting

## 🚀 Getting Started

To view or edit this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tawsifx/hot-gadgets.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd hot-gadgets
   ```

3. **Open in browser:**
   Double click `index.html` or serve via:
   ```bash
   python3 -m http.server 8080
   ```
